¿Cómo funciona la opción de Opapeleo?La propia página de Opapeleo describe estos pasos.
Opapeleo · Visa electrónica para Cuba
1. Datos personalesEscribe los datos tal como aparecen en el pasaporte.
2. PagoCompleta el proceso de compra en Opapeleo.
3. Enlace personalizadoRecibes un enlace por SMS y correo electrónico.
4. Una semana antes del viajeUsas el enlace para completar la información adicional.
5. ResultadoRecibes un PDF con código de barras.
QQL no te pide llenar aquí esos datos. Te explica el camino y te entrega el botón para continuar directamente en Opapeleo.

Importante

QQL no vende ni emite visas. Opapeleo es un proveedor privado. Antes de pagar, revisa directamente sus condiciones, precio y requisitos actuales.
